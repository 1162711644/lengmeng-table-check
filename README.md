# 冷檬数据表格检查 · 表格体检工具

把一份随手做出来的 Excel / CSV 表格，10 分钟体检成"能放心拿去求和、透视、画图"的表。

它是一个 AI Skill（给 Claude / 豆包 等工作流用的技能包），也是一套可以直接在命令行跑的脚本。你给它一张表，它给你两样东西：

- **`原文件名_体检标注.xlsx`** —— 问题单元格按 10 种颜色填充，每格带批注，写清「哪里不对 / 为什么碍事 / 建议怎么改」
- **`原文件名_体检报告.md`** —— 按检查项汇总问题数量、位置、改法、风险等级，并给出优先处理顺序

原表一行都不动，所有标注只写在副本里。

## 为什么需要它

职场表格里最贵的问题不是"格式难看"，而是**肉眼看不见的脏数据**：部门列只在每组首行有值、金额里混着 `1,200元` 和 `约1200`、日期有三种写法、订单号重复了两遍。

这些格子看起来都正常，但一求和就少一块、一透视就整组丢失、一画图时间轴就断。**在动手分析之前先体检**，比事后对着一个错数排查半天便宜得多。

## 能查什么

| 检查项 | 名称 | 判定要点 | 风险 |
| --- | --- | --- | --- |
| 1 | 合并单元格 / 分类列只在首行有值 | 合并区域；或分类列只在每组首行有值、下方连续空 | 高 |
| 2 | 单位混着写 | 同列有的带单位有的不带，或单位变来变去（件/斤/公斤） | 中（建议复核） |
| 3 | 日期格式乱 | 同一列多种写法（3月2日 / 2026-03-02 / 03/02） | 高 |
| 4 | 数字夹字 | 数字列混入约/左右/暂定/未定，或带元/￥符号 | 高 |
| 5 | 一格装多信息 | 姓名电话地址塞进同一个单元格 | 中（建议复核） |
| 6 | 空格子 | 该有数据的单元格为空（零散空，非成组空） | 中 |
| 7 | 多余空行空列 | 整行整列全空、表内空行、游离的合计/说明行 | 中 |
| 8 | 重复记录 | 完全重复行；同一主键（订单号/工号）多行 | 高 |
| 9 | 表头问题 | 首行合并大标题占多列；列名含糊（数据/信息）；重名列 | 中（建议复核） |
| 10 | 跨表命名不统一 | 多 sheet / 多文件同一含义字段名写法不同 | 低（建议复核） |

硬伤类（1/3/4/6/7/8）能机器判定的直接标；需要判断对错的（2/5/9/10）标出来但打上「建议人工复核」，不替用户拍板。

## 快速开始

```bash
pip install openpyxl

# 单个文件 / 多个文件都行，CSV 也支持（会转成 xlsx 副本再标注，原 CSV 不动）
python3 scripts/table_check.py 你的表格.xlsx
python3 scripts/table_check.py 表1.xlsx 表2.csv --outdir ./体检结果
```

默认输出到原文件所在目录；`--outdir` 可以指到别处。

### 先拿一份"脏表"试试

```bash
python3 examples/build_demo.py          # 生成 examples/demo_销售明细.xlsx（故意做脏的样表）
python3 scripts/table_check.py examples/demo_销售明细.xlsx
```

样表里埋了合并大标题、部门悬空、三种日期写法、`1,200元` / `约1200`、"张三 13800138000" 同格、空行、重复订单号、含糊列名和跨 sheet 字段不一致，跑一遍能把 10 项全命中。

## 输出长什么样

```
体检完成：
- 销售明细.xlsx：27 处问题
  标注副本：销售明细_体检标注.xlsx
  体检报告：销售明细_体检报告.md
  体检报告：销售明细_库存_体检报告.md
  跨 sheet 字段一致性提示：
   - 「订单号」、「订单编号」指向同一含义字段，建议统一为「订单号」
```

报告结构固定四块：**总览**（数据量、各检查项命中数、风险分布、优先顺序）→ **分项明细**（位置/问题/碍事/建议）→ **建议人工复核项** → **下一步**。批注与报告都按同一套口径写，方便直接转给同事或实习生照着改。

## 颜色图例

| 检查项 | 颜色 | 色值 |
| --- | --- | --- |
| 1 分类列悬空 | 橙 | `FFC000` |
| 2 单位混写 | 深黄 | `BF8F00` |
| 3 日期格式乱 | 浅蓝 | `BDD7EE` |
| 4 数字夹字 | 粉红 | `FFC7CE` |
| 5 一格多信息 | 浅紫 | `D9C2E9` |
| 6 空格子 | 灰 | `D9D9D9` |
| 7 空行空列 | 深灰 | `808080` |
| 8 重复记录 | 红 | `FF0000` |
| 9 表头问题 | 棕 | `A97142` |
| 10 跨表命名 | 青 | `7FD6D6` |

同一格命中多个检查项时只按最高风险上一种底色，批注里列出全部涉及项，避免颜色打架。

## 作为 AI Skill 安装

`SKILL.md` 就是技能说明（含角色设定、判定标准、铁规矩、报告模板）。把整个仓库放进你的技能目录即可，例如：

```
~/.doubao/agent_mode/workspace/.user_skills/冷檬数据表格检查skill/
├── SKILL.md
└── scripts/table_check.py
```

之后直接跟 AI 说"帮我体检这份表格"，它会自动按这套流程跑脚本、复核结果、交付标注副本与报告。

## 目录结构

```
.
├── SKILL.md                    # 技能说明：判定标准 / 批注口径 / 报告模板
├── scripts/table_check.py      # 体检脚本：扫描 + 填色批注 + 生成报告
├── examples/build_demo.py      # 生成故意做脏的样表，用于验证效果
├── requirements.txt

```

## 设计取舍

- **只标不改**：体检阶段绝不碰用户数据。改数据是另一件事，需要用户明确确认。
- **成组空值 vs 零散空格**：分类列悬空（检查项 1）和零散空格（检查项 6）分开判，避免同一格被标两次。
- **数值列不做分类列判定**：数量列中间出现空缺不会被误判成"分组表头"。
- **汇总行单独处理**：`合计`/`小计`/只有两格有值的游离行按检查项 7 报，不算空格子。
- **保守优于激进**：语义类问题宁可写"建议人工复核"，也不硬改用户表。
